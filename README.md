# 直売所レジ

野菜・卵などの店頭販売用のレジアプリです。タブレットのブラウザで動き、**同期するとき以外はインターネット不要**です。

- アプリ本体：PWA（React + Vite）。一度開けばタブレットに保存され、電波がなくても起動・会計できます
- データ保存：タブレット内（IndexedDB）
- 同期先：Googleスプレッドシート + Google Apps Script（GAS）
  - 商品マスタ：スプレッドシートで編集 → 各タブレットで同期すると反映
  - 売上：タブレットに貯めておき、同期したときにスプレッドシートへ送信

## 1. スプレッドシートとGASの準備

1. Googleドライブで新しいスプレッドシートを作る（名前は「直売所レジ」など）
2. メニューの「拡張機能 → Apps Script」を開く
3. 最初からある `コード.gs` の中身を消して、[gas/Code.gs](gas/Code.gs) の中身を貼り付けて保存
4. 上の関数の選択で `setup` を選んで「実行」
   - 初回は権限の確認が出るので許可する
   - 「商品マスタ」「売上」「売上明細」シートが作られます
   - 実行ログに `合言葉 (TOKEN): xxxxxxxx` と出るので控えておく
     （あとで確認するときは「プロジェクトの設定 → スクリプト プロパティ」）
5. 右上の「デプロイ → 新しいデプロイ」
   - 種類：ウェブアプリ
   - 実行ユーザー：自分
   - アクセスできるユーザー：全員
6. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）を控える

> GASのコードを直したときは「デプロイを管理 → 編集（鉛筆） → バージョン：新しいバージョン」で更新すると、URLが変わりません。

## 2. 商品マスタの書き方

| 列 | 内容 |
|---|---|
| 商品ID | 空欄でOK（同期時に自動で入ります。**一度入ったら変えないでください**） |
| 品名 | レジのボタンに表示される名前 |
| 区分 | 野菜／卵／果物／加工品／その他（タブとボタンの色になります） |
| 価格 | 税込の金額。時価の商品は空欄でOK |
| 時価 | チェックすると、押すたびに価格を入力する商品になります |
| よく使う価格 | 時価の商品で出すワンタッチの価格。`150,200,250` のようにカンマ区切り |
| 表示順 | 小さい順に並びます |
| 非表示 | チェックするとレジに出なくなります（季節外の商品など）。行を消すより安全です |
| よく売れる | チェックすると「よく売れる」タブに表示されます |

## 3. アプリの公開（GitHub Pages の例）

```bash
pnpm install
pnpm build
```

`dist` フォルダの中身を GitHub Pages や Cloudflare Pages などに置きます（HTTPSが必要です）。
手元で試すだけなら `pnpm dev` で起動し、表示されたURLをタブレットで開きます。

## 4. タブレットの準備

1. 公開したURLをタブレットのブラウザで開く（**この1回目はインターネットが必要**）
2. **ホーム画面に追加する**（iPad：共有ボタン →「ホーム画面に追加」／Android：メニュー →「アプリをインストール」）
   - iPadはホーム画面に追加しないと、しばらく使わないとデータが消えることがあります
3. ホーム画面のアイコンから起動 →「設定」でURL・合言葉・端末名（レジ1など）を入れて「保存して今すぐ同期」
4. 一度同期できれば、あとは電波がなくても使えます

## 5. ふだんの使い方

- **販売前**：電波のある場所で「⟳ 同期」を押す（最新の価格を取り込み）
- **販売中**：商品を押す → 「会計へ進む」 → 支払い方法と受け取った金額 → 「会計を完了する」
- **販売後**：電波のある場所で「⟳ 同期」を押す（売上を送信）。画面上部の「未送信」が0件になればOK
- **履歴**：会計の「✎ 修正」（品目・数量・単価・支払い方法を直せます）と「取消」ができます。修正・取消は次の同期でスプレッドシートにも反映されます
- **集計**：日ごと／月ごとに、売上合計・現金・PayPay と「何が何個売れたか」を表示します。「PayPay売上の内訳」では品目別の内訳と、1件ごとの日時・金額を一覧できるので、PayPayの入金明細と照らし合わせられます（集計はその端末で会計した分です）

電波がある場所では、起動時と会計のあとに自動で同期します（レジ操作は待たされません）。

## 注意

- 「未送信」が残っている間は、アプリの削除・ブラウザのデータ消去をしないでください
- 合言葉はURLとセットで守ってください（知っている人は商品マスタを読めます）
- 売上が何年分も貯まってきたら、「売上」「売上明細」シートを年ごとに別ファイルへ移すと快適です
